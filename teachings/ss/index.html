State Space Methods in Control Systems

State variables method in the analysis and design of control systems, canonical forms, controllability, observability, Lyapunov stability, state feedback, observer design, separation principle, and Kalman filter algorithm.

Instructor: Assoc. Prof. İlker Üstoğlu

Term: Fall

Location: ITU Faculty of Electrical and Electronics Engineering

Time: TBA

Course Overview

This course focuses on the modern state-space approach for the analysis and synthesis of multivariable linear control systems:

  • State Modeling: Formulating state-space models, linearization of nonlinear dynamics, and realization of canonical forms.
  • Structural Properties: In-depth evaluation of controllability, observability, stabilizability, and detectability.
  • State Feedback & Synthesis: Full-state feedback design via pole placement and eigenstructure assignment.
  • Lyapunov Stability: Asymptotic and exponential stability analysis using Lyapunov methods and matrix equations.
  • Observer Design & Estimation: Full/reduced-order state observers, observer-based compensators, separation principle, and Kalman filter algorithms.
