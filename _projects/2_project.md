## Project Overview

In this research track, we bridge data-driven control theory with safety-critical guarantees for complex dynamic platforms.

### Key Focus Areas
1. **Data-Driven Predictive Control (DeePC):** Model-free control strategies that leverage online input-output trajectory data instead of explicit parametric models.
2. **Model Predictive Control (MPC):** Real-time constrained optimization running under operational state boundaries.
3. **Safety Filters (CBF):** Integrating Control Barrier Functions solved via Quadratic Programming (QP) to guarantee strict flight envelope protection.
