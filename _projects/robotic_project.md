## Project Overview

Designed as a flexible research and educational platform, this project combines open-source hardware and computer vision frameworks to evaluate control algorithms on physical testbeds.

### Technical Highlights
* **Actuation:** Field Oriented Control (FOC) driven by **SimpleFOC** library for precise motor torque and position tracking.
* **Vision Integration:** Real-time object tracking and target pose estimation via **OpenCV**.
* **Educational Refinement:** Serves as a streamlined baseline for undergraduate robotics projects and laboratory test rigs.
