## Project Overview

Spacecraft operating in low-Earth orbit or deep space face severe environmental torques and actuator limitations. This project develops robust nonlinear predictive controllers for satellite attitude maneuvering and rendezvous trajectories.

### Core Objectives
* Formulating Incremental Nonlinear Dynamic Inversion (**INDI**) schemes for fast attitude stabilization.
* Handling severe external disturbances and inertia tensor uncertainties during orbital maneuvers.
